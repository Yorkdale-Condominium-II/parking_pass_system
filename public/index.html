Bulk import units

Upload an Excel (.xlsx) or CSV file, or paste rows below. Re-running is safe — existing units are updated in place. Two layouts are accepted:

  • List — a header row then one unit per line. Columns: unit_number, floor, kind, business_name, business_contact, notes (only unit_number is required; kind defaults to residential).
  • Floor grid — top-left cell Floor Level, then a floor number per column; column A repeats Unit Number, and each cell below is an actual unit number for that floor. Only the unit numbers you list are imported (blank cells are skipped — nothing is filled in).
